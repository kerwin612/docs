# 租户管理

租户管理功能允许您创建和管理多个租户，每个租户可以拥有自己的网关配置和用户。本文档介绍如何使用租户管理功能。

## 租户概念

租户是 MCP Gateway 中的一个重要概念，用于实现多租户隔离。每个租户可以：

- 拥有自己的网关配置
- 关联特定的用户
- 使用唯一的前缀路径，确保路由不冲突

默认情况下，系统会创建一个名为 "default" 的默认租户。

## 租户配置

在网关配置中，您可以通过 `tenant` 字段指定配置所属的租户：

```yaml
name: "example-gateway"
tenant: "default"  # 指定租户名称

routers:
  - server: "example-service"
    prefix: "/api/example"
    # ...其他配置
```

## 租户管理操作

### 创建租户

创建新租户时，需要提供以下信息：

- **名称**：租户的唯一标识符，不能与现有租户重名
- **前缀**：租户的URL前缀，用于路由隔离，必须唯一
- **描述**：可选的租户描述信息

示例请求：

```json
{
  "name": "tenant1",
  "prefix": "/tenant1",
  "description": "示例租户"
}
```

### 更新租户

您可以更新租户的以下信息：

- **前缀**：更新租户的URL前缀（必须确保唯一性）
- **描述**：更新租户描述
- **状态**：启用或禁用租户

示例请求：

```json
{
  "name": "tenant1",
  "prefix": "/new-prefix",
  "description": "更新后的描述",
  "isActive": true
}
```

### 删除租户

删除租户将移除该租户的所有配置。请谨慎操作，此操作不可逆。

### 查询租户

您可以查询特定租户的详细信息或列出所有租户。

## 租户与用户关联

租户可以与特定用户关联，实现以下功能：

- 用户只能访问和管理其关联的租户
- 管理员可以为用户分配多个租户的访问权限
- 用户可以在网关管理界面中切换当前操作的租户

## 租户选择器

在网关管理界面中，提供了租户选择器功能，允许用户：

- 查看自己有权限的所有租户
- 切换当前操作的租户
- 查看当前租户的配置和状态

## 路由前缀验证

为确保不同租户之间的路由不冲突，系统会进行前缀验证：

- 同一租户内的路由前缀必须唯一
- 不同租户的路由前缀应避免冲突
- 创建或更新路由时会自动进行验证

## 最佳实践

- 为不同的业务场景或团队创建独立的租户
- 使用有意义的租户名称和前缀，便于识别和管理
- 定期审查租户权限，确保安全性
- 在开发和测试环境中使用不同的租户进行隔离
