# 配置版本控制

MCP Gateway 提供了配置版本控制功能，允许您跟踪、管理和回滚网关配置的变更。本文档介绍如何使用配置版本控制功能。

## 版本控制概述

配置版本控制功能允许您：

- 跟踪每个配置的历史变更
- 查看特定版本的配置详情
- 回滚到之前的配置版本
- 比较不同版本之间的差异

每当配置发生变更（创建、更新或删除）时，系统会自动创建一个新的版本记录。

## 版本记录信息

每个版本记录包含以下信息：

- **版本号**：自增的整数，从1开始
- **创建时间**：版本创建的时间戳
- **创建者**：执行操作的用户
- **操作类型**：创建(create)、更新(update)、删除(delete)或回滚(revert)
- **配置内容**：该版本的完整配置内容

## 版本管理操作

### 查看版本历史

您可以查看特定配置的所有历史版本，按版本号降序排列。

### 查看特定版本

您可以查看特定版本的详细信息，包括完整的配置内容。

### 回滚到特定版本

如果当前配置出现问题，您可以回滚到之前的任意版本。回滚操作会创建一个新的版本记录，操作类型为"revert"。

## 存储方式

配置版本记录与配置本身存储在同一数据库中，支持以下存储方式：

- SQLite3
- PostgreSQL
- MySQL

## 版本控制与多租户

版本控制功能与多租户功能无缝集成：

- 每个租户的配置有独立的版本历史
- 版本记录中包含租户信息
- 回滚操作会保持租户信息不变

## 最佳实践

- 在进行重要配置更改前，确认当前配置的版本状态
- 为重要的配置变更添加有意义的描述
- 定期清理过旧的版本记录，避免数据库过大
- 在回滚前，先查看目标版本的配置内容，确保符合预期
