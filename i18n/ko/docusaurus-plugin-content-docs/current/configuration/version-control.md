# 구성 버전 관리

MCP Gateway는 구성 버전 관리 기능을 제공하여 게이트웨이 구성의 변경 사항을 추적, 관리 및 롤백할 수 있습니다. 이 문서에서는 구성 버전 관리 기능을 사용하는 방법을 설명합니다.

## 버전 관리 개요

구성 버전 관리 기능을 통해 다음을 수행할 수 있습니다:

- 각 구성의 이력 변경 사항 추적
- 특정 구성 버전의 세부 정보 보기
- 이전 구성 버전으로 롤백
- 버전 간 차이점 비교

구성이 변경될 때마다(생성, 업데이트 또는 삭제) 시스템은 자동으로 새 버전 레코드를 생성합니다.

## 버전 레코드 정보

각 버전 레코드에는 다음 정보가 포함됩니다:

- **버전 번호**: 1부터 시작하는 자동 증가 정수
- **생성 시간**: 버전이 생성된 타임스탬프
- **생성자**: 작업을 수행한 사용자
- **작업 유형**: 생성, 업데이트, 삭제 또는 되돌리기
- **구성 내용**: 해당 버전의 전체 구성 내용

## 버전 관리 작업

### 버전 이력 보기

특정 구성의 모든 이력 버전을 버전 번호 내림차순으로 정렬하여 볼 수 있습니다.

### 특정 버전 보기

특정 버전에 대한 상세 정보(전체 구성 내용 포함)를 볼 수 있습니다.

### 특정 버전으로 롤백

현재 구성에 문제가 있는 경우 이전 버전으로 롤백할 수 있습니다. 롤백 작업은 작업 유형이 "revert"인 새 버전 레코드를 생성합니다.

## 저장 방법

버전 레코드는 구성 자체와 동일한 데이터베이스에 저장되며, 다음 저장 옵션을 지원합니다:

- SQLite3
- PostgreSQL
- MySQL

## 버전 관리와 다중 테넌트

버전 관리 기능은 다중 테넌트 기능과 원활하게 통합됩니다:

- 각 테넌트의 구성은 독립적인 버전 이력을 가짐
- 버전 레코드에는 테넌트 정보 포함
- 롤백 작업은 테넌트 정보를 유지

## 모범 사례

- 중요한 변경을 하기 전에 현재 구성 버전 상태 확인
- 중요한 구성 변경에 의미 있는 설명 추가
- 데이터베이스 비대화를 방지하기 위해 오래된 버전 레코드 정기적으로 정리
- 롤백하기 전에 대상 버전의 구성 내용을 검토하여 예상과 일치하는지 확인
