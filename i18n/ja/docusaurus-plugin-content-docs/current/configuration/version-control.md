# 設定バージョン管理

MCP Gatewayは設定バージョン管理機能を提供し、ゲートウェイ設定の変更を追跡、管理、ロールバックすることができます。このドキュメントでは、設定バージョン管理機能の使用方法について説明します。

## バージョン管理の概要

設定バージョン管理機能により、以下のことが可能になります：

- 各設定の履歴変更を追跡する
- 特定の設定バージョンの詳細を表示する
- 以前の設定バージョンにロールバックする
- バージョン間の差分を比較する

設定が変更される（作成、更新、または削除）たびに、システムは自動的に新しいバージョンレコードを作成します。

## バージョンレコード情報

各バージョンレコードには以下の情報が含まれます：

- **バージョン番号**：1から始まる自動増分整数
- **作成時間**：バージョンが作成されたタイムスタンプ
- **作成者**：操作を実行したユーザー
- **操作タイプ**：作成、更新、削除、またはリバート
- **設定内容**：そのバージョンの完全な設定内容

## バージョン管理操作

### バージョン履歴の表示

特定の設定のすべての履歴バージョンを、バージョン番号の降順でソートして表示できます。

### 特定バージョンの表示

特定のバージョンの詳細情報（完全な設定内容を含む）を表示できます。

### 特定バージョンへのロールバック

現在の設定に問題がある場合、以前のバージョンにロールバックできます。ロールバック操作は、操作タイプが「revert」の新しいバージョンレコードを作成します。

## ストレージ方法

バージョンレコードは設定自体と同じデータベースに保存され、以下のストレージオプションをサポートしています：

- SQLite3
- PostgreSQL
- MySQL

## バージョン管理とマルチテナント

バージョン管理機能はマルチテナント機能とシームレスに統合されています：

- 各テナントの設定は独立したバージョン履歴を持ちます
- バージョンレコードにはテナント情報が含まれます
- ロールバック操作はテナント情報を保持します

## ベストプラクティス

- 重要な変更を行う前に、現在の設定バージョンの状態を確認する
- 重要な設定変更には意味のある説明を追加する
- データベースの肥大化を防ぐために古いバージョンレコードを定期的にクリーンアップする
- ロールバックする前に、ターゲットバージョンの設定内容を確認して期待通りであることを確認する
